制作步骤校验原先在「下一步」处理和按钮提示中各写一遍；现统一到 `src/game/workflow.ts` 的 `getStepGate`，避免两处规则不一致。铁板折叠缓存按面糊轨迹及食材签名识别，避免计时器刷新时重新生成图层。保留既有订单、评分、金币、关卡、商店、成就和存档规则。

## 独立 AI 试玩与《沙威玛传奇》对标

独立 AI 代理使用 Playwright 实际完成本游戏第一关首单，耗时 31.9 秒，得 93 分、满意度 80；配料匹配为 1/1，交餐后出现下一位顾客。其建议优先补齐「取料 → 撒落 → 折叠遮盖 → 装袋 → 顾客接餐」的连续因果反馈，并把步骤判定集中为一个函数。本轮按此实现了食物分层、折叠遮盖、成品可见和统一步骤校验。

对标依据是[《沙威玛传奇》Steam 官方介绍](https://store.steampowered.com/app/3036080/?l=schinese)，其中展示了按订单制作、定制配料、包裹出餐、不同顾客与厨房升级。代理没有安装或试玩《沙威玛传奇》本体，因此没有声称对其手感或动画逐帧对比。

真实摊制视频的既有步骤对照见[试玩对照记录](BOT_PLAYTEST_AND_REFERENCES.md)。视频画面尚未逐帧测量；此次改动依据玩家实际截图、操作体验和游戏内路径数据。

## 回归结果与剩余限制

- `npm run build`：通过。
- `tests/playthrough.mjs`：自由制作完整出餐、第一关订单和刷新恢复通过。
- `tests/level-and-mobile.mjs`：第一关两单、星级解锁、金币保存和手机触控通过。
- `tests/v5-mobile-flow.mjs`：手机按钮折叠、装袋后可见成品、点击交餐通过。
- `tests/save-and-endless.mjs`：导入导出、消费、升级、重置、损坏存档恢复和无尽纪录通过。

蛋液目前是随路径绘制的 2D 手绘涂层，食材采用程序绘制与错峰落下；尚未达到真实流体模拟或逐帧手绘角色表演的水平。自由模式没有顾客角色，成品显示在试吃说明区。
